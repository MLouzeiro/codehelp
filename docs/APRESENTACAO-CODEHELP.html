O que e o CodeHelp?

Uma plataforma integrada que unifica:

  • Helpdesk com Kanban e SLA
  • Gestao de Clientes completa
  • WhatsApp nativo com menu interativo
  • OS Digital com assinatura via WhatsApp
  • Inteligencia Artificial para insights

Tecnologias

  • Node.js + Express + TypeScript
  • React 18 + Vite + Tailwind
  • Prisma ORM + PostgreSQL
  • whatsapp-web.js
  • Anthropic Claude AI

WhatsApp Nativo

Como funciona

  • Conexao via QR Code (whatsapp-web.js)
  • Menu interativo por numero
  • Classificacao automatica por IA
  • Follow-up periodico
  • Multi-numero (um por departamento)

Fluxo do Cliente

1. Envia mensagem WhatsApp
2. Recebe menu de departamentos
3. Seleciona por numero (1-N)
4. Informa assunto e laboratorio
5. Posicao na fila exibida
6. Atendente assume e resolve
